Latest result per task for each model. Full stack averages FS1 and FS2, and Lead averages L1 and L2; each needs both tasks; with one missing it shows as incomplete. Click a row for task scores, dates and source runs; click a column header to sort.

The effective token rate sets how much you value time saved, and the Best value pick in each table is recommended on that basis. At a lower rate, price counts for more, so cheaper models win even when they are slower. At a higher rate, speed counts for more, so faster models win even when they cost more.

This benchmark was created by Soham Adwani to test the above models on how well they work for the day-to-day tasks he does at Forge, Otterdev and in his personal side projects.

Judged by Claude Opus 5 at max thinking, unrecorded. The judge decides every review score and most of the digest and CLI development scores, so a different judge would give different numbers.

Each score is one run of each task. Scores within 8 points of each other are a tie.

The tasks come from my own work. A score says how a model did on that work, not how good it is in general.

Cost and token counts come from each agent's own session log.
